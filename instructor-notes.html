⚙️ OpenClaw — Commands (run in Ubuntu / WSL)
OPSStart · Restart · Reset · New sessionEverything to control OpenClaw during the day▶

✅ Start / verify do this first

openclaw status # gateway should say “reachable”
openclaw # start it (opens the agent) if it’s down

If it won’t come up cleanly: openclaw doctor --fix

🔄 Restart the gateway after any config change

openclaw gateway run --force # start & replace anything on its port

Example config change then restart:

openclaw config set gateway.auth.mode token openclaw gateway run --force

🆕 Fresh session / clean-slate agent for a clean demo

Best: a new isolated agent that knows nothing — keeps your provider + Telegram. Memory has no “wipe” command, so use a new agent.

openclaw agents add # create a fresh agent — name it: demo openclaw agents bind --help # see how to route Telegram → demo openclaw agents list # confirm openclaw status

Quick fresh conversation (same agent, new thread — may still recall memory):

openclaw agent --session-key agent:main:demo-live --message "Hello — fresh session?" --deliver --reply-channel telegram

See stored sessions / reindex memory:

openclaw sessions list openclaw memory index --force

↩️ Restore after the seminar

openclaw agents bind --agent main --channel telegram # point the bot back openclaw agents delete demo # or remove the demo agent

🧯 Reset destructive — avoid on stage

openclaw reset # wipes config/state (provider key, channels) — you’d re-onboard
openclaw uninstall # removes gateway + local data (CLI stays)

⚠ Only if truly broken. First try openclaw doctor --fix. Back up first: cp -r ~/.openclaw ~/openclaw-backup

⚠ Live tips
  • Everything runs in Ubuntu/WSL, not Windows PowerShell. Node 24.
  • WSL has no systemd → OpenClaw won’t auto-restart after a reboot. If the bot goes quiet, run openclaw.
  • Have Telegram already open and the bot warmed up before doors.
